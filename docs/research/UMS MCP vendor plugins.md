# Seven vendors ship Claude plugins; UMS should route, not rebuild

Of the 22 vendors and platforms checked, **seven publish a Claude plugin or skills repo of their own**: Supermetrics, Amplitude, Resend, Canva, Figma, Notion and Apollo, with HubSpot offering a sales-only plugin. Another eight run an official hosted MCP server and nothing more: Attio, Close, Klaviyo, MailerLite, Ahrefs, Similarweb, Buffer and, on the ads side only, TikTok for Business and Meta. Four social platforms (LinkedIn, YouTube, Reddit, Bluesky) have no official server, plugin or skills in anything found, and X offers only a self-run, unlicensed `xmcp` server. What the plugins add beyond the bare server is procedure and guardrails: previews before bulk actions, paused-by-default campaigns, approval before design commits, mandatory write-safety skills. No official platform server (TikTok, Meta, X) enforces human approval on its own, and only Buffer reaches organic Instagram, TikTok, YouTube, LinkedIn and X posting. UMS should therefore detect and delegate to vendor plugins where they exist, bundle only a thin set of remote MCP entries for the bare-server vendors, and keep every publish, send or spend call behind its own approval gate. Two limits apply to all of this: last-commit dates were not retrievable for any repo, and "none found" for the four social platforms rests on a handful of searches, not primary developer docs.

## Seven vendors ship plugins, and the licences decide what UMS may copy

The clearest cases come with source repos and licences read from GitHub. Supermetrics' `supermetrics-marketing` plugin is MIT, carries **21 skills** (six role skills such as performance-marketer and demand-gen, four supporting skills, eleven platform skills including email, CRM and social publishing) and bundles an OAuth `.mcp.json` ([repo](https://github.com/supermetrics-public/claude-marketing-plugin)). Its Claude listing advertises "42 workflows", a count the repo does not reproduce, so UMS should cite the repo figure ([listing](https://claude.com/plugins/supermetrics)). Amplitude's `amplitude` plugin is MIT with **28 skills** across core analytics, product insights, session replay, AI-agent analytics, instrumentation and briefings ([repo](https://github.com/amplitude/mcp-marketplace)); earlier sources said 25+. Resend's repo is MIT with five skills (`resend`, `agent-email-inbox`, `resend-cli`, `react-email`, `email-best-practices`), a hosted MCP at `mcp.resend.com/mcp` that needs OAuth and no API key, and a 3,577-install Claude listing ([repo](https://github.com/resend/resend-skills), [listing](https://claude.com/plugins/resend)). Apollo's plugin is MIT with four slash skills (`/apollo:prospect`, `enrich-lead`, `sequence-load`, `analytics`) ([repo](https://github.com/apolloio/apollo-mcp-plugin)). Canva's skills repo is Apache-2.0 and lists ten active skills, while the Claude page says six, an unresolved conflict ([repo](https://github.com/canva-sdks/canva-skills), [listing](https://claude.com/plugins/canva)).

Two vendors are less open. Figma's plugin installs with `claude plugin install figma@claude-plugins-official` and bundles skills for design implementation, Code Connect and design-system rules, but `figma/mcp-server-guide` states **no licence** and ties use to Figma's developer terms, so UMS may point to it and must not copy from it ([repo](https://github.com/figma/mcp-server-guide)). Notion's plugin from Notion Labs holds 12 cookbook skills, including "Plan marketing campaigns", and its README page states no licence; an earlier MIT claim came from a search summary and stays unconfirmed ([repo](https://github.com/makenotion/claude-code-notion-plugin)). HubSpot is the odd one: its site lists a Claude connector plus a "HubSpot Sales Plugin" (call prep, daily brief, follow-up, pipeline pulse, contact lookup), but no standalone skills repo or licence turned up, and the plugin targets sales, not marketing ([HubSpot](https://www.hubspot.com/claude)). Claude's "Anthropic verified" badge on Apollo, Resend, Supermetrics and Canva is useful but proves no authorship by itself; what makes these official in practice is that the source repos sit in vendor-named organisations.

The remaining marketing vendors are bare servers. Attio's connector is "Made by Attio" and Anthropic-verified, added February 2026 ([listing](https://claude.com/connectors/attio)); its skills on the market are community work. Close has a connector and a documented server at `mcp.close.com/mcp` with OAuth or an API key ([docs](https://developer.close.com/mcp)). Klaviyo runs a hosted server and a beta local package, and its own guidance leaves skills to customers ([docs](https://developers.klaviyo.com/en/docs/klaviyo_mcp_server)); the only Klaviyo skill found is a community MIT one. MailerLite offers an OAuth server on all plans, free included, running server v4.16.0 ([docs](https://developers.mailerlite.com/mcp)). Ahrefs has the hosted `api.ahrefs.com/mcp/mcp` with OAuth, and its old local repo is archived with no skills repo in the organisation ([docs](https://docs.ahrefs.com/mcp/docs/introduction), [GitHub](https://github.com/ahrefs)). Similarweb launched an official connector with Anthropic and a hosted server whose requests burn data credits ([blog](https://www.similarweb.com/blog/updates/announcements/similarweb-claude), [docs](https://developers.similarweb.com/docs/claude-mcp-integration)). Note that Anthropic's own marketing plugin already carries connectors for Ahrefs, Amplitude, Canva, HubSpot, Klaviyo, Similarweb and Supermetrics, so a user may already have several of these installed before UMS arrives ([knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins/tree/main/marketing)).

## What a plugin adds beyond the bare MCP server is procedure and a brake

A bare server hands Claude tools; a plugin hands it a method. The sharpest examples are guardrails. Supermetrics keeps reports read-only, changes anything only on request after showing the exact edit and getting approval, requires write access to be enabled in the Supermetrics Hub, creates new campaigns **paused**, logs changes, and ships no hooks or telemetry; its writes reach Google Ads, Meta, Microsoft, TikTok, LinkedIn, Snapchat and social posts ([repo](https://github.com/supermetrics-public/claude-marketing-plugin)). Apollo's `sequence-load` previews before it bulk-adds contacts ([repo](https://github.com/apolloio/apollo-mcp-plugin)). Canva's plugin edits existing designs with preview and approval before commit, resizes for Facebook, Instagram and LinkedIn, bulk-creates from brand templates (Enterprise only) and runs a brand-kit check, but describes no publishing ([listing](https://claude.com/plugins/canva)). Figma's server instructions make the `/figma-use` skill mandatory before any write call, a procedural lock the bare server does not provide ([Figma Help](https://help.figma.com/hc/en-us/articles/39888612464151)). Resend's skills add React Email and deliverability knowledge that no server could expose as a tool ([Resend blog](https://www.resend.com/blog/introducing-email-skills)).

The other half of the value is cost. Claude Code defers MCP tool definitions by default and caps tool output at 25,000 tokens, so extra servers cost little at startup; a skill still pays for itself by telling the model which narrow query to run, which matters for Ahrefs, ads and analytics exports ([Claude Code MCP docs](https://code.claude.com/docs/en/mcp), [Anthropic](https://www.anthropic.com/engineering/code-execution-with-mcp)). Relevance varies. For a marketing plugin, Supermetrics, Amplitude, Resend, Notion and Canva map directly to UMS jobs (performance reporting, product analytics, lifecycle email, campaign planning, creative); HubSpot and Apollo are sales-led; Attio, Close, Klaviyo and MailerLite offer only tools, so UMS must supply the procedure itself.

## Official social servers cover ads, not organic posting, and approval is your job

The social picture is lopsided. TikTok's official server is paid-ads only: two URLs, a full ~400-tool endpoint and a layered ~40-tool one, with a help page updated August 2026 that says nothing on auth, scope or audit and notes workflows can run without human intervention at each step ([TikTok help](https://ads.tiktok.com/resources/help/article/about-tiktok-for-business-mcp-server)). Meta's official servers (Ads, devtools, WhatsApp Business) use OAuth, and the docs warn an agent "can directly call anything your granted permissions allow, without asking you first"; they never mention Instagram or Facebook Page organic publishing ([Meta docs](https://developers.facebook.com/documentation/mcp)). X's `xdevplatform/xmcp` is a local server with about 119 operations including `createPosts` and `deletePosts`, an optional tool allowlist, and no licence file ([GitHub](https://github.com/xdevplatform/xmcp)); its "official" status is inferred from the organisation name only.

For LinkedIn, YouTube, Reddit and Bluesky, nothing official turned up. Google's remote MCP list had no YouTube endpoint as of a 24 November check, and Google's open-source Ads MCP gained a video-upload tool that serves ads, not channels ([Sociality.io](https://sociality.io/blog/connect-youtube-to-claude/), [PPC Land](https://ppc.land/google-ads-mcp-server-gains-4-write-tools-still-cant-change-budgets/)). One guide saw a "Develop with MCP" link on LinkedIn's developer homepage on 22 October, with no docs behind the login, which is a lead and no launch ([contextbolt](https://contextbolt.com/blog/linkedin-mcp/)). Reddit's API is closing to new apps, with sources disagreeing on whether the cut-off was 31 October 2026 or 12 January 2027 ([fast.io](https://fast.io/resources/mcp-server-for-reddit/)). Community Bluesky servers use app passwords ([8b-is](https://github.com/8b-is/bluesky-mcp)). The popular community LinkedIn server reuses a browser login, and its own FAQ concedes LinkedIn prohibits automated access ([The Ad Spend](https://theadspend.com/blog/linkedin-ads-mcp)).

That leaves **Buffer** as the only vendor server that publishes organic posts to Instagram, TikTok, YouTube, LinkedIn and X from one OAuth connection, with modes `addToQueue` (default), `shareNow`, `shareNext` and `customScheduled`. Buffer's page says the server does not enforce approval, that `create_post` can publish at once, and that `delete_post` is irreversible, so approval lives entirely in the client ([Buffer](https://developers.buffer.com/guides/integrations/mcp.html)). Its auth is also contested: a bearer-key header appears on one Buffer page and OAuth on another ([Buffer developer docs](https://developers.buffer.com/guides/integrations/mcp)). Add TikTok's own rule that unaudited clients post privately only and even audited Direct Post needs per-post user approval ([TikTok guidelines](https://developers.tiktok.com/doc/content-sharing-guidelines)), and fully autonomous TikTok publishing is non-compliant by design.

## How UMS should use each vendor

The rule is to delegate where a vendor owns a maintained workflow layer, bundle where only a server exists, and stay silent where the source is unsafe. The table gives the decision per vendor.

| Route | Vendors | What UMS does |
|---|---|---|
| Route to vendor plugin | Supermetrics, Amplitude (US or EU URL), Resend, Canva, Figma, Notion; Apollo and HubSpot for sales-led tasks | Detect the plugin, delegate the workflow, link the install command; copy no skill text except under MIT or Apache-2.0 with attribution (Supermetrics, Amplitude, Resend, Apollo, Canva) |
| Bundle remote MCP only | Attio, Close, Klaviyo, MailerLite, Ahrefs, Similarweb, HubSpot MCP; Buffer as optional | Ship `https://` entries in `.mcp.json`, write UMS's own skills for procedure |
| Optional, ads only | TikTok for Business (prefer the ~40-tool layered URL), Meta Ads | Document, do not bundle; keep spend out of scope |
| Neither | LinkedIn, YouTube, Reddit, Bluesky, X `xmcp` | Draft plus manual publish; never bundle browser-login or password-based servers |

Mechanics matter as much as the list. Claude Code resolves duplicate server names by scope, with local over project over user over plugin over claude.ai connectors, and does not merge entries, so a UMS-bundled `resend` server would be shadowed by a user's own and could double-register next to the vendor plugin; UMS should detect first and bundle only what is missing ([Claude Code MCP docs](https://code.claude.com/docs/en/mcp)). Plugin servers register as `mcp__plugin_<plugin>_<server>__<tool>`, so UMS's guard hooks must match that pattern, and a matcher on a bare server name never fires. Because `claude -p` and Agent SDK runs cannot finish OAuth, any scheduled marketing job needs a prior interactive login or header-key auth. UMS should pin `oauth.scopes` to read wherever the vendor lets it, and treat HubSpot writes, Klaviyo and Resend sends, Buffer publishes, ads spend and every CRM sequence enrolment as approval-required.

Directory rules shape the packaging. A remote MCP server that a submitted bundle references must itself be submitted as a connector, so a lean `.mcp.json` of well-known vendors reduces review risk; the Software Directory Policy, per a summary needing a live check, also excludes autonomous money movement, which argues for keeping ads writes out of the UMS bundle and deferring to Supermetrics' paused-by-default flow ([Policy](https://support.claude.com/en/articles/13145358-anthropic-software-directory-policy)). The combination to avoid in one session is reading untrusted social text, reading private CRM or ads data, and holding a write tool; split a read-only research agent from a gated publisher ([Claude Code MCP docs](https://code.claude.com/docs/en/mcp)). Scan any community server before enabling it, for example with Cisco's offline YARA mode ([Cisco](https://github.com/cisco-ai-defense/mcp-scanner)).

## Conclusion

The research moves the question from "which MCP servers to bundle" to "who owns the workflow layer". For six marketing jobs a vendor already does, in a licence UMS can read, what a bare server lacks, so UMS adds most value by becoming a router that knows which vendor plugin is installed and which job each one takes, not by duplicating their skills. Its own writing effort should go where no vendor ships procedure: CRM and lifecycle-email servers (Attio, Close, Klaviyo, MailerLite), SEO and competitor intelligence (Ahrefs, Similarweb) and the cross-platform publishing gate, where the only organic-publishing server (Buffer) enforces nothing.

Several facts could change this advice and should be rechecked before shipping: the contents of Anthropic's official marketplace file (only the first ~1,000 of 4,451 lines were read, showing Apollo and Amplitude), HubSpot's skills repo and licence, last-commit dates for every repo, Meta's Instagram organic publishing plans, and LinkedIn's "Develop with MCP" programme. The absence findings for LinkedIn, YouTube, Reddit and Bluesky should be written into UMS as "none found as of 26 November 2026", not "none exist".
